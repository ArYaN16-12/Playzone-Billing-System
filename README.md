# Playzone-Billing-System

## Overview
PlayZone Billing System is a console-based application developed in C++ to automate billing and customer record management for entertainment centers and play zones. The system helps manage customer details, generate bills, track transactions, and maintain records using file handling.

## Features
* Add and manage customer records
* View available games and pricing
* Generate bills based on selected games and number of turns
* Store transaction records for future reference
* View customer transaction history
* File-based data storage using text files
* Simple and user-friendly Command Line Interface (CLI)

## Technologies Used
* C++
* File Handling
* Text Files
* Command Line Interface (CLI)

## Project Structure
* `customers.txt` – Stores customer information
* `games.txt` – Stores available games and their prices
* `transactions.txt` – Stores billing and transaction records
